# 结果页

本文说明结果页，解码与流程不在范围内。

## 职责

展示一张图片的解码结果。页面接收图片 URI 与解码状态，把原图、位置标注和结果卡片显示出来，并把复制、打开网址两个操作交给 `AppViewModel`。

## 打开与关闭

`AppViewModel` 把 `activeSheet` 设为 `Sheet.Result` 时页面出现。关闭方式有两个：左上角返回箭头，以及系统返回手势或返回键。

返回键由页面自己处理。操作栏打开时，第一次返回只关闭操作栏；没有操作栏时才回到主界面。页面不处理返回键时，按下会直接退出应用。

## 页面结构

页面占满屏幕，内容多于屏幕时可以上下滚动。顶部固定一个返回箭头，下方依次是图片区和状态区。

状态区按 `DecodeUiState` 的取值显示四种内容之一：

| `barcodes` | `decodeError` | 显示 |
|---|---|---|
| null | null | 图片加「正在识别…」 |
| 空列表 | null | 图片加「未识别到二维码」 |
| 非空 | null | 图片加位置标注与卡片列表 |
| 任意 | 非空 | 图片加错误卡片，卡片里同时显示原因文字 |

两种状态文字居中显示，文字内容取 `strings.xml`。

## 图片与位置标注

图片宽度填满容器，高度按宽高比自适应。位置标注画在图片上方的一层画布上。

每条结果用 `cornerPoints` 画一个多边形，填充为半透明，边框为同色实线，宽度约 3dp。位置点为空的结果不画多边形，卡片照常显示。

坐标按图片原始尺寸与显示尺寸的比例换算，位置点乘该比例后落在画面上。

点击画布时，把点击位置按同一比例还原成图片坐标，再判断落在哪个多边形里，点到哪条就弹出那条的操作栏。点正好落在边上或顶点上，也算点中。判断方法是从点击位置向右画一条水平线，数它穿过几条边：穿过奇数条说明点在多边形内，穿过偶数条说明在外。

## 卡片列表

每条结果一张卡片，从上到下按结果顺序排列。卡片有圆角与 2dp 描边，描边颜色取这条结果对应的调色板颜色。卡片内显示文本和格式名，文本过长自动换行。

点击卡片弹出操作栏，位置在卡片内的点击处。

## 操作栏

操作栏是浮在页面上的小面板，含两个按钮：复制和打开。打开按钮只在文本以 `http://` 或 `https://` 开头时出现，判断只看前缀，不做进一步校验。

点击空白区域、再次按返回键、或执行任一操作后，操作栏关闭。结果内容变化时也会关闭，避免指向已不存在的结果。

## 调色板

六组颜色，按结果顺序循环取用，第七个结果复用第一组。每组含三个颜色：多边形填充色带 25% 透明度，描边色不透明，卡片背景为同色系浅色。

## 图片加载失败

图片读不出来时，图片区留出高度显示一行错误文字，内容按 `spec/error-handling.md` 的规则构造，同时记录日志。解码结果区不受影响。

## 边界情况

| 情况 | 行为 |
|---|---|
| 结果数量超过六条 | 调色板颜色循环使用 |
| 某条结果没有位置点 | 不画这条结果的多边形，卡片照常显示与操作 |
| 解码进行中用户按返回 | 回到主界面，未完成的解码任务随之取消 |
| 解码进行中收到新的分享图片 | 页面内容整体替换为新图的结果，旧任务取消 |
| 操作栏打开时结果内容变化 | 操作栏关闭 |
| 图片加载失败 | 图片区显示错误文字，其余区域正常 |
