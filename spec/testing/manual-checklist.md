# 发布前手工验证清单

设备测试覆盖不到的部分，每轮发布在真机上过一遍。每条都要记录结果，失败写明现象。

## 图片来源

1. 从相册选一张含二维码的图片，选择器正常拉起，选中后进入结果页。
2. 从文件选一张图片，选择器正常拉起，过滤条件只显示图片。
3. 从相机拍照，权限申请、拍照、解码三步都正常。
4. 从其它应用分享一张图片进来，直接进入结果页。
5. 从其它应用分享多张图片，本应用不出现在分享列表中。

## 识别效果

6. 含一维码的图片，ML Kit 能识别，格式名正确。
7. 含多个二维码的图片，结果全部列出，卡片颜色循环，多边形贴住二维码。
8. 不含二维码的图片，显示未识别到二维码，不显示错误卡片。
9. 损坏或格式不支持的图片，显示错误卡片，原因文字包含真实信息。
10. 旋转 90 度或 270 度的照片，ML Kit 能识别；微信引擎可能漏检。
11. 只有文本没有位置点的结果，卡片显示文本，图片上没有多边形。

## 交互

12. 点击多边形、点击卡片都能弹出操作栏，点击空白处关闭。
13. 操作栏打开时按返回键，只关闭操作栏，页面不退出。
14. 再次按返回键回到主界面；主界面按返回键退出应用。
15. 复制按钮把文本写入剪贴板。
16. 文本是网址时出现打开按钮，点击后进入浏览器；文本不是网址时不出现。

## 打包产物

17. 发布包开启混淆与资源压缩后，两个引擎都能出结果。只出 ML Kit 结果也算失败。
18. 四个按 CPU 架构拆分的安装包，各自只含对应架构的原生库，安装后能解码。
19. 在 Android 7 到 Android 10 的设备上验证一次，重点是图片选择器的回退路径与相机权限。

## 记录方式

每轮验证追加一节，写清日期、版本、设备、结果。示例：

```
2026-11-08 / v1.1 / Pixel 8 模拟器
1 通过
17 失败：崩溃，原因待查
```
